# Cruz & Farias — Mobile V5

Versão corrigida para impedir cortes de texto em celulares.

## Principais ajustes
- Títulos menores e com quebra natural em 720, 390, 340 px e abaixo.
- Remoção de line-clamp que ocultava parte dos textos.
- Botões e selos com múltiplas linhas quando necessário.
- Proteção para palavras, e-mails e títulos longos.
- Cards, experiências, abas e chamadas sem largura mínima que cause estouro.
- Fallback JavaScript que reduz discretamente a fonte somente quando houver overflow real.

## Publicação
Substitua o index.html atual pelo arquivo desta pasta. Os demais arquivos podem permanecer na raiz do projeto.
