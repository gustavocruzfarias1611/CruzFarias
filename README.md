# Cruz & Farias — versão mobile editorial V4

Versão autônoma em um único `index.html`, com imagens, CSS e JavaScript incorporados.

## Melhorias
- Conteúdo mobile reduzido e hierarquizado.
- Modelo de valor substituído por resumo compacto no celular.
- Indicadores em grade 2x2.
- Pilares, Método Conecta e serviços com detalhes expansíveis.
- Experiências com abas horizontais e painel resumido no celular.
- Textos, botões, espaçamentos e tipografia revisados.
- Compatibilidade com telas de 320 px a desktops grandes.

## Publicação
Envie `index.html`, `favicon.ico`, `robots.txt` e `sitemap.xml` para a raiz do projeto.
