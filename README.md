# Cruz & Farias Consultoria — versão comercial 10/10

Esta versão reorganiza o site para funcionar como centro comercial da Cruz & Farias Consultoria.

## Estrutura

- `index.html`: página institucional principal.
- `para-parceiros/index.html`: página da Rede Conecta.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu móvel, animações, barra de progresso e gerador de link para parceiros.
- `favicon.svg`: ícone da marca.
- `robots.txt` e `sitemap.xml`: configuração básica de SEO.
- `backup-site-anterior.html`: cópia do código original enviado.

## Melhorias implantadas

- Menu reduzido e sem barra lateral.
- Apenas dois CTAs na primeira tela.
- Promessa comercial clara e orientada a resultado.
- Quatro pilares de atuação.
- Comunicação pública unificada no Método Conecta.
- Três níveis de contratação: Diagnóstico, Programa Conecta e PMO Fracionado.
- Três experiências principais, sem percentuais estimados apresentados como resultados.
- Página exclusiva para parceiros.
- Gerador de link de indicação com código e parâmetros UTM.
- Links diretos para o diagnóstico, portfólio, e-mail e WhatsApp.
- Layout responsivo, acessível e otimizado para SEO.

## Publicação na Vercel

Envie todo o conteúdo desta pasta para o repositório usado pela Vercel. Não altere a estrutura da pasta `para-parceiros`.
